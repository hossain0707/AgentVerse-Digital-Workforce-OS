FREE LOCAL CONNECTION GUIDE

Use your AgentVerse employees on your PC

Export an employee workspace, then connect the portable records to a compatible MCP desktop client. Your documents and lessons are read from a file you explicitly choose; the bridge makes no network calls and requires no cloud account.

ChatGPT account note: ChatGPT Plus/Pro is not a reusable API key. This downloadable local stdio MCP bridge works with compatible local MCP clients such as Claude Desktop, but it is not a verified direct ChatGPT app connection. For ChatGPT today, use ChatGPT & PC → Copy task for ChatGPT. A future remote MCP integration would need OAuth and hosted security controls.

Four steps to your local MCP bridge

1
In the AgentVerse workspace, create or select an employee, add knowledge and click Export all employees. Save your JSON file locally and keep it private.
2
Install Node.js 20 or newer on your Windows, macOS or Linux computer. The MCP bridge uses built-in Node modules only; no npm packages or paid account are needed.
3
Download this bridge script and save it in a predictable folder:

Download AgentVerse local MCP server

4
Register the script with a local stdio MCP-capable client, pointing it to your exported JSON. Example configuration for a desktop MCP client:
{
  "mcpServers": {
    "agentverse": {
      "command": "node",
      "args": [
        "C:/AgentVerse/agentverse-mcp.mjs",
        "C:/AgentVerse/AgentVerse-portable-employees.json"
      ]
    }
  }
}

Example Windows paths—replace both paths with your actual file locations. On macOS/Linux, use absolute POSIX paths. MCP-capable client configuration formats vary, so follow your client's specific instructions.

What the bridge can do

List employees, read professional instructions, search knowledge excerpts, prepare a task prompt, and produce offline source-backed text extracts. With explicit approval, it can save new lessons or task answers into a new portable JSON backup.

What it does not do

It cannot automatically access your ChatGPT account, synchronize browser data, crawl websites, open private computer files outside the selected export, execute arbitrary code, fine-tune AI model weights or guarantee AI output accuracy.

Bring your changes back

When the bridge records a lesson or result, it creates a new AgentVerse-updated-….json file beside your input backup. Go to the web workspace and choose Import backup to replace your local workspace with that updated copy. Export your current work before importing. This is a manual transfer, not live synchronization.

Security: do not grant an untrusted desktop client access to private exports. All matching source excerpts sent to a connected model may be transmitted under that model provider's data handling terms. Local MCP access does not create an employer-isolated encrypted vault.
